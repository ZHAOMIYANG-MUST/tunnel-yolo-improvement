# 候选改进点清单（供导师讨论）

> 课题：基于改进 YOLOv8 的隧道衬砌渗漏检测
> 现状：改进① WIoU v3 损失已完成实验，测试集 mAP50 0.929→0.959，Precision 0.871→0.934，零参数开销
> 本文档列出从近年文献中筛选的候选改进点，按"问题依据"组织，供组合方案讨论

---

## 候选改进点（按推荐优先级）

### 候选 A：CBAM 注意力机制 ★推荐
- **出处**：Woo et al., *CBAM: Convolutional Block Attention Module*, ECCV 2018
- **做法**：通道注意力 + 空间注意力串联，插入 backbone 的 C2f 模块后
- **针对问题**：隧道低光照、渗漏水渍与电缆/接缝纹理易混淆（误检）
- **文献先例**：Tunnel-YOLO（Eng. Appl. Artif. Intell. 2025）等隧道检测工作验证有效
- **代价**：参数量增加约 1~3%

### 候选 B：SimAM 无参注意力 ★推荐（与 CBAM 二选一或对比）
- **出处**：Yang et al., *SimAM: A Simple, Parameter-Free Attention Module*, ICML 2021
- **做法**：基于神经科学的 3D 注意力权重，**零参数**
- **针对问题**：同 CBAM，但不增加模型体积，答辩时"轻量化"故事更好讲
- **文献先例**：隧道车辆检测版 Tunnel-YOLO（Transp. Res. Rec. 2025）采用

### 候选 C：BiFPN 多尺度特征融合
- **出处**：Tan et al., *EfficientDet*, CVPR 2020
- **做法**：替换 PAN-FPN 为双向加权特征金字塔
- **针对问题**：不同尺寸水渍（0.01~0.5+ 面积跨度大）的多尺度适配
- **代价**：结构改动较大，工作量中等

### 候选 D：P2 小目标检测层
- **出处**：YOLO 系列通用改进，多项隧道病害论文采用
- **针对问题**：本数据集实测小目标仅 2%，**动机偏弱**——若换用含裂缝的三类数据集（裂缝为细小目标）则动机恢复
- **备注**：可改述为"增强窄条目标的高分辨率特征保留"

### 候选 E：Shape-IoU / MPDIoU 损失（对比项）
- **出处**：Zhang et al., *Shape-IoU*, 2023；Sirko & Sergey, MPDIoU, 2023
- **做法**：与 WIoU 同属 IoU 损失家族，可作为对比实验或二选一
- **针对问题**：细长目标回归精度（已由 WIoU 部分解决，用作横向对比可丰富实验）
